# Report20 - 基于AI Agent的星舰火箭模拟

SpaceX 星舰（Starship）是人类迄今研制的最大、推力最强的运载火箭：两级全复用、不锈钢箭体、总高约121米、起飞质量约5000吨、起飞推力约7500吨力，一级Super Heavy由33台Raptor发动机驱动，回收时由发射塔的机械臂（"筷子"）直接在空中夹住。2024年10月的第5次飞行测试（IFT-5）实现了首次塔架捕获，二级也完成了受控再入和海上垂直溅落。

本报告要求使用 kimi-code 等 AI 编程 Agent，开发一套尽可能逼真的星舰起飞—回收全过程模拟程序。（选择本报告的同学只需完成这一个报告即可，无需再选做其他3个报告。）

**这个报告的重点有两个**：
1. 仿真的物理逼真度：动力学、气动、发动机、飞行时序都要有真实依据；
2. 学会驾驭 AI Agent 做复杂工程：如何把大任务拆解成一系列有效的 prompt、如何审读和验证 Agent 生成的代码、如何用真实数据检验仿真结果。

## 星舰真实物理参数（以 IFT-5 飞行的 Block 1 构型为参考）

整体：总高 121.3 m，直径 9 m，不锈钢箭体，满载总质量约 5000 t。

| 参数 | 一级 Super Heavy | 二级 Starship |
| --- | --- | --- |
| 高度 | 71 m | 50.3 m |
| 直径 | 9 m | 9 m |
| 干重 | ~275 t | ~100 t |
| 推进剂质量 | ~3400 t（LOX 2700 t + CH4 700 t） | ~1200 t |
| 发动机 | 33 × Raptor 2 | 3 × Raptor（海平面）+ 3 × RVac（真空） |
| 单台海平面推力 | ~230 tf（2.3 MN） | ~230 tf |
| 起飞/初始总推力 | ~7500 tf（73.5 MN） | ~1250 tf |
| 海平面比冲 | 327 s | 327 s |
| 真空比冲 | 350 s | 380 s（RVac） |

Raptor 发动机：液氧/液甲烷全流量分级燃烧循环，燃烧室压力约 350 bar，混合比约 3.6:1，海平面型可摆动 ±15°；一级仅内圈 13 台可摆动、可重复点火（用于 boostback 和着陆反推），外环 20 台固定。

## 要求

1. 使用 kimi-code 等 AI 编程 Agent（Claude Code、Cursor 等也可以）完成开发，需要：
   - 把任务拆解成一系列 prompt，报告里记录关键的 prompt 与 Agent 的响应、迭代修改的过程
   - 对 Agent 生成的代码进行审读、运行和验证，不能盲目相信，说明你发现并修正了哪些问题
2. 建立物理模型，包括：
   - 变质量刚体动力学：质量、转动惯量随推进剂消耗变化
   - 发动机模型：推力、质量流量、海平面/真空比冲差异、节流与开关机时序
   - 大气模型：密度、压强、声速随高度变化（如 ISA 标准大气）
   - 气动模型：阻力系数、参考面积、动压，Max-Q 的计算
3. 模拟全过程飞行剖面：
   - 上升段：程序角/重力转弯，Max-Q、MECO、热分离
   - 一级：boostback、栅格翼气动下降、landing burn、塔架捕获（给出捕获成功的高度/速度/位置判定条件）
   - 二级：入轨 → 再入（腹部朝前、襟翼控制姿态）→ 峰值加热 → 翻转 → landing burn → 垂直溅落
4. 用上面 IFT-5 的实测数据校验仿真，给出关键事件（Max-Q、MECO、捕获、溅落）的误差分析
5. 可视化：高度/速度/动压/推进剂余量随时间曲线，飞行轨迹的 2D 或 3D 动画（matplotlib、three.js、Unity 等均可），发动机工作状态图
6. 加分项（选做）：风场扰动与单台发动机故障的容错仿真、闭环制导算法、实时交互界面、逼真的3D渲染
7. 按照`report_template.md`撰写自己的报告。
