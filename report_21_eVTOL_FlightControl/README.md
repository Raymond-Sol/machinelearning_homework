# Report21 - eVTOL高可靠飞行控制系统仿真

eVTOL（电动垂直起降飞行器，electric Vertical Take-Off and Landing）是城市空中交通（UAM / 空中出租车）的核心载具。它载客飞行，对安全性的要求接近民航客机：按照 EASA SC-VTOL 等适航标准，灾难性失效概率需低于 10^-9 / 飞行小时，因此飞控系统必须做高可靠架构设计——多余度计算机、传感器冗余、动力冗余、故障检测与重构（FDIR）。

倾转旋翼构型的 eVTOL（如 Joby S4：6个电动倾转旋翼）飞行剖面覆盖：垂直起飞 → 过渡（transition，旋翼从前倾逐步转到水平，升力由旋翼切换到机翼）→ 巡航平飞 → 过渡返回 → 垂直降落。其中**过渡段**气动特性剧烈变化、旋翼与机翼气动强耦合，是失速与失控事故的高发阶段，也是飞控设计的核心难点。

本报告要求开发一套 eVTOL 高可靠飞行控制系统的仿真程序，逼真模拟全飞行流程，并通过故障注入验证系统的高可靠性。（选择本报告的同学只需完成这一个报告即可，无需再选做其他3个报告。）

## 高可靠设计参考

* **余度架构**：三余度飞控计算机 + 表决（如三取二）；传感器冗余（IMU×3、GNSS×2、气压计×3、空速计×2）；动力冗余（6旋翼布局，单电机失效后仍可安全飞行与降落）；电池分组冗余
* **FDIR**：故障检测（残差/一致性检查）→ 故障隔离 → 控制重构（控制量重新分配）
* **安全状态机**：正常 / 降级 / 应急模式，包线保护，中断起飞，应急着陆
* **适航参考**：EASA SC-VTOL-01、DO-178C（机载软件）、DO-254（机载硬件）

## 要求

1. 建立逼真的被控对象模型（六自由度）：
   - 刚体六自由度动力学（质量、惯量）
   - 旋翼气动模型：推力与诱导功率（动量/叶素理论或简化模型），旋翼间下洗干扰
   - 机翼气动模型：升力/阻力随迎角变化，含失速特性
   - 倾转机构模型：倾转角速率限制、机电动态
   - 电池模型：SOC、放电电压下垂、大功率放电限制
2. 实现全流程飞行控制，覆盖完整剖面：
   - 垂直起飞/降落段：姿态稳定 + 位置/高度控制
   - **过渡段**：倾转角与空速的协同调度（增益调度或分段控制律），保证升力从旋翼平滑切换到机翼、全程不失速、不失控
   - 巡航段：机翼升力飞行，速度/高度/航向控制
   - 控制律方法（PID/LQR/MPC等）自选，说明选择理由与参数整定过程
3. 高可靠架构设计（本报告的重点）：
   - 三余度飞控计算机仿真与表决逻辑
   - 传感器冗余与一致性检查、故障传感器隔离
   - 单电机/动力通道失效后的控制量重分配（control re-allocation），并证明剩余控制量仍足够
   - FDIR 完整流程：检测 → 隔离 → 重构 → 记录
   - 安全状态机与模式切换逻辑（含降级飞行的构型与速度限制）
4. 故障注入仿真框架，至少覆盖：
   - 悬停、过渡、巡航三个阶段各发生一次单电机失效
   - 单个IMU漂移/卡死
   - 倾转机构卡滞（如卡在45°）
   - 每种故障下给出系统的检测时间、重构后的飞行状态、能否继续完成任务或安全着陆
5. 风扰仿真：常值风、阶跃阵风（1-cos 型），选做 Dryden 湍流模型
6. 可视化与数据分析：飞行动画（2D/3D）、姿态/轨迹/空速/倾转角/各电机功率曲线、故障注入与切换日志、过渡段平滑性定量分析（迎角峰值、高度掉落量、过载等）
7. 加分项（选做）：整机应急降落伞仿真、把你的设计逐条映射到 EASA SC-VTOL 相关条款、蒙特卡洛批量故障仿真与统计、半实物风格的多进程架构（飞控与被控对象分离运行）
